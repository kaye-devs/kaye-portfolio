Letters Through Six Months — A Personal Digital Diary

A personal interactive journal website built as a digital space for love, memories, and connection during my partner’s six-month Police Training. Designed to document everyday moments, thoughts, letters, photos, and memories while we’re apart, the website also gives him a private space to send messages and share media back with me.

Built with HTML, CSS, JavaScript, Supabase, and GitHub, the project features user authentication, journal entries, a digital scrapbook, photo/video memories, a countdown, and a two-way messaging system. The goal was to create something more personal than a traditional website—a living diary that allows us to stay connected throughout the six months.

Tech Stack: HTML5 • CSS3 • JavaScript • Supabase • GitHub • Responsive Web Design

Frameless — One Click Away

A modern business website designed as a digital portfolio and interactive package viewer for Frameless, a photography and videography service provider. The website gives customers an easy and visually engaging way to explore available photography and videography packages, compare services, and find the package that best fits their event.

The website organizes services into clear categories such as Birthday, Debut, Christening, Wedding, and Portrait Session, with each category featuring Package A, Package B, and Package C and their corresponding inclusions and pricing. Customers can simply select a category to view the available packages without having to browse through a long page.

The design was developed with a clean, elegant, photography-focused aesthetic that highlights Frameless' visual identity while keeping the user experience simple and accessible. The website is also designed to be responsive across desktop and mobile devices, allowing potential clients to browse packages conveniently from their phones.

Tech Stack: HTML5 • CSS3 • JavaScript • Responsive Web Design

Project Type: Business Website • Service Portfolio • Interactive Package Viewer
